nghttp2 version 2 - HTTP/2 C Library
====================================

This is an implementation of the Hypertext Transfer Protocol version 2
(HTTP/2) in C.  This implementation is based on :rfc:`9113`.

It is a complete rewrite of nghttp2 v1, aiming for better performance,
security, and API ergonomics.

The project is hosted at `github.com/nghttp2/nghttp2-v2
<https://github.com/nghttp2/nghttp2-v2>`_.
